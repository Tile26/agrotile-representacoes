# AgroTile Representações

Sistema de gestão comercial da AgroTile.

## Módulos
- Categorias e produtos
- Clientes organizados por rotas
- Vendas e histórico por cliente
- Controle de estoque e movimentações
- Relatórios por período e rota

## Requisitos operacionais
- Banco de dados persistente
- Autenticação e autorização no servidor
- Histórico de alterações
- Backups e recuperação
- Testes automatizados

## Status
Fundação inicial do repositório. Ainda não está pronto para uso comercial.
